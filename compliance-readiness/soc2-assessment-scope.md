# SOC 2 Readiness Assessment Scope

**Client:** Northstar Financial Technologies  
**Engagement:** Simulated Cybersecurity GRC and IT Audit Assessment  
**Assessment Type:** Internal SOC 2 Readiness Assessment  
**Status:** Proposed assessment scope

## 1. Purpose

Evaluate selected cybersecurity controls against applicable SOC 2 Trust Services Criteria using synthetic evidence and simulated audit procedures.

This engagement is intended to identify control gaps and recommend improvements. It is not an independent SOC 2 examination.

## 2. Trust Services Categories

| Category | Scope | Assessment Focus |
|---|---|---|
| Security | In Scope | Access controls, risk management, change management, monitoring, incident response |
| Availability | In Scope | Backups, recovery readiness, operational resilience |
| Confidentiality | Out of Scope | Separate confidentiality-category assessment |
| Processing Integrity | Out of Scope | Transaction processing accuracy and completeness |
| Privacy | Out of Scope | Personal information lifecycle management |

## 3. Systems in Scope

- Microsoft Entra ID and Microsoft 365
- Windows 11 endpoints
- AWS cloud environment
- GitHub repositories and development workflows
- Selected third-party SaaS services
- Security logging and monitoring processes
- Backup and recovery processes

## 4. Assessment Approach

The assessment will examine:

1. Control design effectiveness.
2. Simulated operating effectiveness.
3. Evidence completeness and reliability.
4. Identified control deficiencies.
5. Risk-based remediation recommendations.

All evidence will be synthetic and clearly identified as simulated.

## 5. Assessment Limitations

- No production system access.
- No real customer or employee information.
- No independent audit opinion.
- No SOC 2 Type I or Type II attestation.
- No claim of certification or compliance.
- No conclusion regarding controls outside the defined scope.

## 6. Framework Mapping Implications

SOC 2 Common Criteria will be considered for applicable security controls.

Availability criteria will be considered where relevant to backup, recovery, and operational resilience.

The proposed A1.2 mapping for OPS-03 may therefore be evaluated as part of the assessment.

Framework references will remain subject to validation against authoritative criteria before final audit conclusions.
